# Planning Model

Simpler developmental action-planning model for object manipulation and exports an interactive HTML animation.

The current version compares:

- **Younger-like**: moves the object to the target first, then rotates it.
- **Older-like**: moves and rotates simultaneously.

The HTML output shows:
- object start and target positions
- target orientation as a dashed arrow
- current object position
- current object orientation
- path taken so far
- target uncertainty over time

## Files
- `model.py` - model and HTML animation export
- `action_animation.html` - interactive animation generated by script
- `trial_metrics.json` - summary metrics for runs

## Model Assumptions

1. The agent begins with a noisy estimate of the target position and target orientation.
2. The younger-like controller organises behaviour sequentially to translate then rotate.
3. The older-like controller organises behaviour integratively to translate and rotate at the same time
4. Movement is damped near the target to prevent oscillation.
5. Target uncertainty decays over time and is visualised in the lower panel.
